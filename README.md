Eclipse

Eclipse is a clock application built with plain HTML, CSS, and JavaScript, with no external frameworks or dependencies. It displays the current time in both analog and digital formats, and users can switch between the two views using a simple toggle. The analog clock features smoothly moving hour, minute, and second hands, while the digital view shows the time along with the current day and date. The entire project is contained in a single HTML file, making it lightweight and easy to run or host anywhere.
